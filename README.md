# TRAVELEON Service Provider App

A React Native mobile application for local service providers in Sri Lanka's tourism industry to showcase their services and connect with travelers.

## 🌟 Features

- **User Authentication**: Secure login and registration system for service providers
- **Profile Management**: Manage business profile and contact information
- **Service Listings**: Add and manage various tourism services:
  - Accommodations
  - Restaurants
  - Vehicle Rentals
  - Tour Guide Services
  - Adventure Packages

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn
- Expo CLI
- Firebase account

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/TRAVELEON-Service.git
```

2. Install dependencies:

```bash
cd TRAVELEON-Service
npm install
```

3. Configure Firebase:

   - Create a Firebase project
   - Add your Firebase configuration to `firebaseConfig.ts`

4. Start the development server:

```bash
npm start
```
